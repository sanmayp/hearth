# Hearth overview for judges

## Problem

- One developer now runs many coding agents at once.
- Agents span many projects and many computers.
- Bugs and features land at the same time.
- No one can track all that in memory.
- Agents give no board unless you read files or code.

## Solution

- Hearth is one control room for agents, tasks, and notes.
- It marks windows working, stuck, or waiting for you.
- It names billing and API errors as stuck reasons.
- Approve or stop runs from the phone with code plus audit.
- Voice commands read the board aloud, read-only by default.

## Demo path

1. `git clone https://github.com/sanmayp/hearth.git`
2. `cd hearth`
3. `scripts/demo.sh`
4. Watch the board mark agents working, stuck, or waiting.
5. Open Needs-you and approve one item with code.
6. Speak one voice command and hear the board read back.
