# ASD-STE100 in Hearth

Hearth writes all user text in simplified English. The rules come
from ASD-STE100, the standard for clear technical writing. Short
words beat long words. Short sentences beat long ones.

## Rules we follow

- One idea per sentence. Tops at about 20 words.
- Present tense. Active voice. No idioms. No slang.
- Warnings come before actions, never after.
- Same word for the same thing, every screen.
- Numbers as digits. Units spelled out on first use.
- No jokes in errors. Say what broke and what to do next.

## Example

Bad: "Oops, something went sideways with the thingamajig!"

Good: "The bridge is down. Check the token file. Try again."

## Where it applies

UI copy, docs, comments, errors, and model prompts all follow it.
Tests may use plain names too. Demo data says it is fake.
