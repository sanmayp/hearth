# Contributing

Small branches welcome. One change per branch. Keep it calm.

## Rules

- Write short plain sentences. See [docs/ASD-STE100.md](docs/ASD-STE100.md).
- Rust: `cargo fmt --check`, `cargo clippy -- -D warnings`, crate tests.
- Web: `svelte-check`, unit tests, `vite build`.
- Never commit keys, tokens, hosts, or personal data. Scan first.
- Demo data stays fake and says so.
- No trailer lines in commits. One line of summary, then plain detail.
